CSS 长度单位

了解 Web 前端开发中常用的长度单位

px — 像素 (绝对单位)

屏幕上最小的显示点，是最常用的单位。

width: 200px;

em — 相对于父元素字体大小 (相对单位)

1em = 父元素的 font-size。此处父级字体为 20px。

width: 10em; height: 2em;

rem — 相对于根元素字体大小 (相对单位)

1rem = 根元素 (html) 的 font-size，默认 16px。

width: 12.5rem; height: 2rem;

% — 百分比 (相对单位)

相对于父元素对应属性的百分比。

width: 50%;

vw — 视口宽度 (相对单位)

1vw = 视口宽度的 1%。

width: 30vw;

vh — 视口高度 (相对单位)

1vh = 视口高度的 1%。

height: 15vh;

vmin / vmax — 视口最小/最大值 (相对单位)

vmin: 取宽高中较小的 1%；vmax: 取宽高中较大的 1%。

width: 20vmin; width: 15vmax;

pt — 点 (绝对单位)

1pt = 1/72 英寸，常用于打印。

width: 100pt; height: 20pt;

pc — 派卡 (绝对单位)

1pc = 12pt = 1/6 英寸。

width: 6pc; height: 1.5pc;

in / cm / mm — 物理单位 (绝对单位)

in: 英寸 (1in = 96px = 2.54cm)；cm: 厘米；mm: 毫米。

1in = 2.54cm = 25.4mm = 96px

ch — 字符宽度 (相对单位)

等于字体中 "0" 字符的宽度。

20ch 宽度
width: 20ch;

ex — x 高度 (相对单位)

等于字体中 "x" 字符的高度。

3ex 高度
height: 3ex;

绝对单位对比表

以 96dpi 为基准的换算关系：

单位名称换算类型
px像素1px = 1/96 in绝对
pt点1pt = 1/72 in绝对
pc派卡1pc = 12pt绝对
in英寸1in = 96px = 2.54cm绝对
cm厘米1cm = 37.8px绝对

相对单位对比表

相对于其他属性的单位：

单位名称参考基准用途
em字体相对父元素 font-size字体、间距
rem根字体相对根元素 font-size全局尺寸
%百分比父元素对应属性宽度、高度
vw视口宽视口宽度响应式布局

vmax视口最大vw/vh 中较大者大屏适配

exx 高度"x" 字符高度垂直对齐

使用建议

• 响应式布局推荐使用 rem、vw/vh、%
• 字体大小推荐使用 rem（便于全局缩放）
• 间距推荐使用 em 或 rem
• 边框等细节可使用 px
• 全屏元素使用 100vh / 100vw
• 打印样式使用 pt、cm、mm、in
