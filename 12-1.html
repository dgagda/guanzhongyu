CSS 变量（自定义属性）

使用 var() 定义和引用可复用的 CSS 值

什么是 CSS 变量

CSS 变量（Custom Properties）允许在 CSS 中定义可复用的值，通过 var() 函数引用。变量名以 -- 开头。

:root {
    --guan-primary: #3498db;
    --guan-radius: 8px;
}

.box {
    background: var(--guan-primary);
    border-radius: var(--guan-radius);
}

全局变量（:root）

在 :root 中定义的变量为全局变量，整个页面都可以使用。

primary
success
danger
warning
:root {
    --guan-primary: #3498db;
    --guan-success: #2ecc71;
    --guan-danger: #e74c3c;
    --guan-warning: #f39c12;
    --guan-radius: 8px;
    --guan-shadow: 0 2px 8px rgba(0,0,0,0.15);
}

局部作用域变量

变量可以在任何选择器中定义，只在当前元素及其子元素中生效。

父元素定义了 --guan-local-color
子元素继承父元素的变量
.scope-demo {
    --guan-local-color: #9b59b6;
    background: var(--guan-local-color);
}
.scope-demo .child {
    background: var(--guan-local-color); /* 继承父级变量 */
}

回退值（Fallback）

当变量不存在时，可以使用 var() 的第二个参数作为默认值。

变量 --guan-not-exist 不存在，使用回退值 #1abc9c
.fallback-demo {
    background: var(--guan-not-exist, #1abc9c);
}

JavaScript 动态修改变量

通过 JS 可以动态获取和设置 CSS 变量，实现主题切换等交互效果。

点击下方按钮，通过 JS 改变 --guan-js-color 变量 
// 设置变量
document.getElementById('gzy_jsDemo').style.setProperty('--guan-js-color', '#3498db');

// 获取变量
getComputedStyle(element).getPropertyValue('--guan-js-color');

CSS 变量 vs Sass/Less 变量

特性 CSS 变量 Sass/Less 变量
运行时修改 支持（JS 可操作） 不支持（编译后固定）
作用域 支持（继承机制） 支持（词法作用域）
浏览器支持 现代浏览器 需编译
动态主题 非常适合 不适合
语法 --name: value; $name: value;

使用建议

• 主题色、字体、间距等设计令牌推荐使用 CSS 变量
• 需要动态切换主题时，只需修改变量值即可
• 变量命名建议使用语义化名称，如 --guan-primary-color
• 合理使用回退值，增强代码健壮性
• 避免在循环中频繁读取变量（性能考虑）
