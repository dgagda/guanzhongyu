JavaScript 程序结构：条件与循环

作者：管忠煜 —— 演示 if...else / switch 条件结构与 for / while / do...while 循环结构

一、条件结构

1. if...else（判断分数等级）

if (gzy_score >= 90) { ... } else if (gzy_score >= 60) { ... } else { ... }

2. switch（数字转星期）

switch (gzy_day) { case 1: gzy_name = "星期一"; break; ... default: gzy_name = "输入有误"; }

二、循环结构

1. for 循环（1 ~ n 累加求和）

var gzy_sum = 0; for (var gzy_i = 1; gzy_i <= gzy_n; gzy_i++) { gzy_sum += gzy_i; }

2. while 循环（1 ~ n 阶乘）

var gzy_fact = 1, gzy_j = 1; while (gzy_j <= gzy_n) { gzy_fact *= gzy_j; gzy_j++; }

3. do...while 循环（先执行后判断，输出偶数）

var gzy_k = 2; do { gzy_out += gzy_k + " "; gzy_k += 2; } while (gzy_k <= 20);
知识点小结：程序结构分为顺序结构、条件结构（分支）和循环结构三种。 条件结构按条件选择执行路径（if...else、switch）；循环结构重复执行代码块（for、while、do...while）， 可用 break 跳出循环、continue 跳过本次循环。注意 do...while 至少执行一次循环体。
