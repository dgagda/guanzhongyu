JSON 展示

作者：管忠煜 —— JSON 概念、语法规则、JSON.parse 与 JSON.stringify 互转演示

一、什么是 JSON

JSON（JavaScript Object Notation，JS 对象简谱）是一种轻量级的数据交换格式， 独立于语言和平台，常用于前后端数据传输。

  • 数据由键值对组成，键必须用双引号包裹
  • 值可以是：字符串、数字、布尔值、null、对象、数组
  • 数据之间用逗号分隔，大括号保存对象，方括号保存数组
  • 不支持注释、不支持函数
{ "name": "管忠煜", "age": 20, "isStudent": true, "hobbies": ["网页设计", "篮球"] }

二、一个完整的 JSON 数据示例

{ "students": [ { "id": 1, "name": "张三", "score": 92 }, { "id": 2, "name": "李四", "score": 85 }, { "id": 3, "name": "王五", "score": 78 } ], "class": "402班", "teacher": "管忠煜" }

对象里嵌套数组，数组里又嵌套对象，这是接口返回数据最常见的结构。

三、JS 对象 → JSON 字符串：JSON.stringify()

var gzy_obj = { name: "管忠煜", age: 20 }; var gzy_json = JSON.stringify(gzy_obj);

四、JSON 字符串 → JS 对象：JSON.parse()

var gzy_jsonStr = '{"brand":"Apple","price":8999}'; var gzy_obj2 = JSON.parse(gzy_jsonStr); // 之后即可 gzy_obj2.brand 取值
知识点小结：JSON 是前后端交换数据的标准格式，接口返回的数据基本都是 JSON 字符串。 JSON.stringify() 把 JS 对象变成 JSON 字符串（发送给服务器），JSON.parse() 把 JSON 字符串还原成 JS 对象（接收解析）。 使用 fetch 时，response.json() 内部就是帮我们完成了 JSON.parse 的工作。
