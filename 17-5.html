JavaScript 的两种定时器

作者：管忠煜 —— setTimeout 一次性定时器 与 setInterval 周期性定时器

1. setTimeout

在指定时间后只执行一次，可用 clearTimeout() 清除，避免定时器未执行就取消。

var gzy_timer = setTimeout(function () { // 时间到，执行一次 }, 3000); // 取消：clearTimeout(gzy_timer);

2. setInterval （周期性执行）

每隔指定时间就执行一次，会一直重复，必须用 clearInterval() 停止。

var gzy_timer2 = setInterval(function () { gzy_count++; // 每 1 秒执行一次 }, 1000); // 停止：clearInterval(gzy_timer2);

两者区别：setTimeout 只执行一次（延迟执行），适合延时提示、自动关闭弹窗； setInterval 按固定间隔反复执行，适合时钟、轮播图、计时器。 两者都返回一个定时器 id，分别用 clearTimeout(id) 和 clearInterval(id) 清除， 否则定时器会一直占用内存（页面卸载前务必清理）。
